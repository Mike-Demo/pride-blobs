# Contact Pridatar

Pridatar is a free, open-source side project maintained by Mike Demopoulos.
The best way to reach out depends on what you need:

- **Bugs, flag corrections, feature ideas**: open an issue at
  https://github.com/Mike-Demo/pride-blobs/issues
- **Email**: hey.demo@mikedemo.email
- **GitHub**: https://github.com/Mike-Demo
- **X**: https://x.com/Mike_Demo
- **Bluesky**: https://bsky.app/profile/mikedemo.bsky.social

There is no support desk, no SLA, and no paid support tier — this is a
nights-and-weekends project. Issues on GitHub get the fastest response.
