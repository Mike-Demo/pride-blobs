# Pridatar pricing

Pridatar is **free**. There are no tiers, no paid plans, no trials, and no
usage limits — the generator runs entirely in your browser, so there is
nothing to meter.

## What you get, free forever

| Feature | Included |
| ------- | -------- |
| Avatar generation (any seed) | Yes |
| 15 pride flags | Yes |
| 15 shapes (blob styles, cat, bunny, bear, fox, flag) | Yes |
| 8 expressions | Yes |
| Idle animations | Yes |
| SVG, PNG, and animated GIF export | Yes |
| Shareable avatar URLs | Yes |
| Embed snippets (React, inline SVG, CSS, CodePen) | Yes |
| Commercial reuse (MIT license, with attribution) | Yes |
| Accounts required | None — there are none |
| API / programmatic access | None exists |

## Why it can be free

There is no server runtime, no database, and no per-user cost: rendering
happens on the visitor's own device. The project's only costs are domain and
static hosting, covered by the maintainer.
