# Open source & credits

Pridatar is built on open source software. Every library and artwork source it
relies on is credited here, and on the full credits page at
https://blobs.gay/licenses.

## Upstream artwork

Pridatar is a pride-focused fork of [blobatar](https://github.com/Alain00/blobatar)
by Alain00, released under the MIT License. The blob rendering approach, face
expressions, and animation system derive from that project.

## Project
